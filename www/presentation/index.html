05 · ARCH / I-OKQUEUE.RS
I/O MULTIPLEXING

One thread.
One queue.
Many sockets.

The core engine uses BSD kqueue to monitor every live file descriptor from a single dispatch loop.
SCALABILITY
Avoids thread-per-connection overhead. One async loop, file-descriptor monitoring only.
PERFORMANCE
O(1) retrieval — consistent latency under heavy load.
EVENT FILTERS
EVFILT_READ for ingestion, EVFILT_WRITE for buffered delivery.

07 · ARCH / HTTPPARSER.RS
WEB PROTOCOL IMPLEMENTATION

A handwritten HTTP/1.1 stack.

HTTP/1.1 Parsing
RFC 7230
Hand-rolled state machine: request line → headers → optional chunked body. Strict parser refuses ambiguous framing to prevent request smuggling.
// states are explicit. no allocations on the hot path. enum State { RequestLine, Headers, Body(Mode), // ContentLength | Chunked | None Trailer, Done, Error(ParseErr), }
