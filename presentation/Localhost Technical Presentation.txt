# slide 5
I/O MULTIPLEXING VIA KQUEUE
The core engine utilizes the kqueue event notification interface to manage multiple concurrent connections efficiently on macOS.


Scalability: Avoids thread-per-connection overhead by using an asynchronous event loop based on file descriptor monitoring.
Performance: O(1) complexity for event retrieval, ensuring consistent response times under heavy load
Event Filters: Precise handling of EVFILT_READ for ingestion and EVFILT_WRITE for buffered delivery.


# slide 6
SOCKET MANAGEMENT
Non-blocking Lifecycle & State Integrity

Implicit State Flow: Accept → Ingest → Process → Deliver
  • Monitors partial I/O and protocol boundaries via kqueue filters.

Operational Guardrails:
  • UUID-based session persistence across transactions.
  • Resource isolation via fixed MAX_CONNECTIONS pool.
  • Proactive cleanup of dead descriptors via timeouts.

# slide 7
WEB PROTOCOL IMPLEMENTATION
HTTP/1.1 Parsing
Handwritten state machine for parsing request lines, headers, and chunks. Strict adherence to RFC 7230 to prevent protocol smuggling.
Dynamic Routing
Utilizing the Host header to map traffic to virtual servers. Support for CGI (Python/Bash) and session management via UUID cookies.

# slide 8
REQUEST FLOW MECHANICS
Connection Acceptance: The kqueue listener identifies new SYNs and registers the client FD.
Buffer Ingestion: Non-blocking read() operations fill per-session buffers until headers/body are complete.
Semantic Analysis: The internal HTTP parser identifies the method, target, and host to find the appropriate handler.
Payload Delivery: Responses are buffered and transmitted via non-blocking write() when EVFILT_WRITE is triggered.

# slide 11
MULTI-TIERED TESTING STRATEGY
Mandatory Peer Reviews: Focus on memory safety, logic flow, and error handling in Rust.
Automated Unit Tests: Isolated testing of the HTTP parser, URI builder, and Session Manager components.
Manual Scenarios: Injection of malformed packets and stress testing the kqueue event loop.
Integration Tests: End-to-end cycles using reqwest to verify server behavior against realistic HTTP traffic.

# slide 12
GITHUB ACTIONS PIPELINE
Our Continuous Integration (CI) workflow automates the validation of every code submission.
Build Validation: Verifies compilation against the Rust toolchain on target environments.
Static Analysis: Uses Clippy to enforce idiomatic Rust standards and lint for potential errors.
Regression Suite: Automated execution of integration tests to ensure logic remains intact across commits.
